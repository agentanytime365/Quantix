## BACKEND API

POST /api/generate-test-cases

Request:
{
userStory,
testTypes,
testingTypes,
count,
format
}

Validation:

* userStory required (1–2000 chars)
* testTypes not empty
* testingTypes not empty
* count must be 3,5,8,10

Behavior:

* Check daily quota (limit 5)

* If exceeded → return 429

* Call OpenAI

* Return structured JSON

Response:
{
testCases: [],
usage: {
usedToday,
limitPerDay: 5
}
}

GET /api/usage

* Returns usage info

priority: "low" | "medium" | "high"
}
